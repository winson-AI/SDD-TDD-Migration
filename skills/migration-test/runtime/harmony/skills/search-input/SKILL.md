# 文本输入技能

本技能用于规范输入文本索的操作流程。当任务涉及搜索框/文本框输入场景时，必须按以下步骤顺序执行。

## 操作流程

### 第一步：点击输入框唤出键盘

- 调用`execute`工具执行："点击xx文本框/输入框/搜索框，唤出键盘"
- 目的：激活输入框并唤起软键盘。

### 第二步：处理页面跳转

- **必须**判断页面是否发生了跳转，键盘是否已经唤出。
- **如果发生跳转**：在跳转后的新页面上重新定位输入框，调用`execute`工具执行："点击xx文本框/输入框/搜索框，唤出键盘"
- **如果未发生跳转**：继续执行第三步。

### 第三步：清理输入框
- 如果没有文字，可直接进入下一步输入操作
- 如果有文字，调用`execute`工具执行："调用`clear_text`工具清除文字"，**仅调用一次**
- 清理后检查输入框状态：
  - 如果仍可见文字，且和未清除前的一致、或者颜色偏淡、或者光标在文字开头，则视为**占位符**（实际内容为空），可直接进入下一步输入操作

### 第四步：输入搜索内容

- 调用`execute`工具执行："使用 `input_text` 工具将xxx内容写入输入框"

### 第五步：处理剪贴板兜底情况

- 在第四步之后，检查输入框状态：
  - **如果输入框中已包含输入的内容**：输入成功，无需后续操作。
  - **如果输入框为空，但键盘剪贴板提示栏显示了需要输入的内容**：调用`execute`工具执行："点击键盘剪贴板中xxx文字，将其插入输入框"

## 注意事项

- 每次点击后都要确认当前页面状态，以判断是否发生跳转。
- 剪贴板提示栏通常位于键盘上方，显示最近复制的文本内容。
- 占位符文字通常为灰色/淡色，并非实际输入内容，不要误判为残留文字。
- 如果输入框光标在文字的最前面，则该文字一定是占位符，并非实际输入内容，不要误判为残留文字。
