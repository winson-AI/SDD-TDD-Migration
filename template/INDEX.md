# 模板索引

`{{...}}` 是待填字段，示例值不是真实结果；实例化后消除占位符，初始 pending/null/untested 保持真实状态。模板只描述形状，门禁以 Ledger 为准；每步模板由游标步骤的 `templates` 给出，`reading.py show --template <名>` 取单份，路径见[资产根与留存](../skills/migration-protocol/references/storage-layout.md#总则)。
