# 弹窗消除 (Dismiss Popups)

此技能用于识别并消除屏幕上的干扰元素，包括真实的系统/应用弹窗和视频内容中伪造的“假弹窗”。

## 执行步骤

1. **观察当前页面状态**：
    - 检查是否处于“首页”、“关注”等短视频流页面。
    - 识别当前屏幕上的遮挡物是否具有明显的 UI 交互特征（如：右上角的 `x` 按钮、底部的“以后再说”等文字）。

2. **识别并处理“真弹窗”**：
    - 如果识别到 `x` 关闭图标，或“以后再说”、“暂不”、“我知道了”、“取消”等关闭类按钮，且其位置固定在 UI 层级中，则直接点击该区域。
    - 等待 0.5 秒，确认弹窗是否消失。

3. **识别并处理“视频/内容假弹窗”**：
    - **短视频播放页**：如果当前处于视频流中，且弹窗样式看起来非常突兀（如：清晰度与背景不一、带有明显的点击诱导、且无法通过常规
      UI 探测识别其关闭按钮），则该弹窗极有可能是视频内容的一部分。
        - **操作方法**：调用 `go_back()` 返回或向上滑动（Swipe Up）切换到下一个视频。
    - **首页/推荐/关注列表页（如网格布局）**：如果发现某个内容卡片（如视频缩略图）内部包含看起来像弹窗的元素（如“签到领钱”红色悬浮窗），但它
      **只存在于单个卡片内**且**并未遮挡整个屏幕或底部导航栏**，则判定为内容的一部分。
        - **⚠️ 绝对禁令**：**严禁点击**这类缩略图中的“假弹窗”！这通常是博主制作的封面诱导，点击会导致意外进入该视频，产生误操作。直接忽略，继续寻找你真正需要的操作目标。

4. **处理权限请求（系统级）**：
    - 如果是系统级弹窗（如位置、存储权限），除非任务明确需要，否则一律选择“仅在使用中允许”或“拒绝/取消”。

5. **验证清理结果**：
    - 确认主操作区域（如：搜索框、底部导航栏）已无遮挡。

## 注意事项

- **识别优先级**：优先寻找并点击真实的 UI 关闭按钮。
- **防止误操作**：如果无法确定是弹窗还是正常页面内容，优先选择“返回”或“向上滑动”而不是盲目点击弹窗中心区域。
- **连续弹窗**：有些应用会连续弹出多个通知，需循环检查直到屏幕干净。
- **特殊情况**：在视频流中，如果“弹窗”随着视频背景一起滚动，那一定是视频里的假弹窗，直接划走即可。
